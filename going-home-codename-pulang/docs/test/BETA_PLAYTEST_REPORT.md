## Participant feedback

- When did riding become boring, if at all?
- Did any dialogue feel preachy or unnatural?
- Did the layoff feel believable?
- Did the motorcycle feel old but cared for?
- Did the places feel Indonesian?
- Did arriving in Banyuwangi feel emotionally satisfying?
- Was first-person movement comfortable? Record duration, settings and any point the participant chose to stop.
- Was mobile control tiring or difficult to reach?

Do not continue a comfort test after a participant wants to stop. A shorter session is still useful evidence; it is not a passed extended-comfort gate.
